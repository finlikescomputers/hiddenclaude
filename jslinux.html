This is a self-contained x86 PC emulator (v86, the actively-maintained open-source successor to Fabrice Bellard's original JSLinux) running a real Debian Linux kernel entirely inside this browser tab — nothing is installed on the Chromebook itself. Everything needed to run it (the emulator engine plus the kernel and disk image) is fetched on demand the first time you click Start Linux, so you need internet access once per session to boot it; after that it runs locally in the tab.

Boot is slow — this is a full systemd-based Debian, and v86 emulates a 32-bit CPU in software with no hardware acceleration, so expect roughly 5-6 minutes from clicking Start to a login prompt. Log in as root with password root (or debian / debian).

Networking: the virtual machine's network card is bridged to the real internet through a public relay (wss://relay.widgetry.org/), and this image has a static IP baked in, so it connects automatically at boot — no commands needed. Once you're at a shell, ping, curl, wget, and apt can all reach the internet (e.g. ping -c3 8.8.8.8). The "Network" indicator above turns green once real traffic is seen.

Click inside the black screen to send keyboard input to the VM; click outside it to release your keyboard back to the browser. The screen switches from a text console to a pixel-rendered one partway through boot — that's normal, not a freeze.
