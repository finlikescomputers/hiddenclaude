Idle Network: not connected
This is a self-contained x86 PC emulator (v86, the actively-maintained open-source successor to Fabrice Bellard's original JSLinux) running a real Linux kernel entirely inside this browser tab — nothing is installed on the Chromebook itself. Everything needed to run it (the emulator engine and the Linux kernel image, ~15 MB total) is fetched from public CDNs the first time you click Start Linux, so you need internet access once per session to boot it; after that it runs locally in the tab.

Networking: the virtual machine's network card is bridged to the real internet through a public relay (wss://relay.widgetry.org/). It does not connect automatically — once you see the ~% prompt, run udhcpc to get an IP address, then you can use ping, wget, curl, and telnet from inside the guest (e.g. ping -c3 8.8.8.8 or wget http://example.com). The "Network" indicator above turns green once real traffic is seen.

Click inside the black screen to send keyboard input to the VM; click outside it to release your keyboard back to the browser. This boots Buildroot Linux (busybox userland) — it's a minimal environment, not a full desktop, but it's a real Linux shell with internet access.
