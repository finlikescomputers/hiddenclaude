Idle Network: not connected
This is a self-contained x86 PC emulator (v86, the actively-maintained open-source successor to Fabrice Bellard's original JSLinux) running a real Linux kernel entirely inside this browser tab — nothing is installed on the Chromebook itself. Everything needed to run it (the emulator engine plus the Arch Linux kernel and root filesystem) is fetched on demand from public CDNs the first time you click Start Linux, so you need internet access once per session to boot it; after that it runs locally in the tab. It boots straight to a root@localhost shell — no login prompt or password.

Networking: the virtual machine's network card is bridged to the real internet through a public relay (wss://relay.widgetry.org/). It does not connect automatically — once you're at a shell, run dhcpcd (or udhcpc) to get an IP address, then use ping, curl, wget, or pacman to reach the internet (e.g. ping -c3 8.8.8.8). The "Network" indicator above turns green once real traffic is seen.

Click inside the black screen to send keyboard input to the VM; click outside it to release your keyboard back to the browser. Note the emulator is a real but slow 32-bit CPU (v86 can't do 64-bit) — expect Arch's package manager and services to run noticeably slower than on real hardware, especially on first boot while filesystem data streams in over the network.
